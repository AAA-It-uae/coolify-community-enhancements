# Security Policy

## Supported scope

Security fixes are considered for the current `main` branch and the latest documented/tested enhancement versions.

These modifications are version-specific. Older Coolify snapshots or locally modified variants may require a separate assessment.

## Reporting a vulnerability

Please **do not open a public issue** for a security vulnerability.

Use GitHub's private vulnerability reporting flow instead:

1. Open the repository's **Security** tab.
2. Open **Advisories**.
3. Select **Report a vulnerability**.
4. Include the affected enhancement, Coolify version, reproduction steps, impact, and any proposed mitigation.

Please remove credentials, private hostnames, tokens, customer data, and other sensitive information from screenshots and logs unless they are strictly required for the private report.

## Response approach

Reports will be reviewed for reproducibility and impact. If a fix is required, remediation will be developed privately where appropriate and published after the issue is addressed.
